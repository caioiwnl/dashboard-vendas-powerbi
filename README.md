# Dashboard de Vendas Interativo — Power BI

## 📊 Sobre o projeto

Dashboard interativo desenvolvido no **Microsoft Power BI** com o objetivo de analisar o desempenho comercial por meio de indicadores e visualizações dinâmicas.

O projeto permite explorar os dados de vendas, acompanhar resultados ao longo do tempo e comparar diferentes informações para facilitar a interpretação dos indicadores e apoiar a tomada de decisões.

## 🎯 Objetivos

* Analisar a distribuição das vendas por gênero.
* Comparar os resultados de vendas entre diferentes anos.
* Acompanhar indicadores de desempenho comercial.
* Visualizar informações de forma dinâmica e intuitiva.
* Facilitar a identificação de tendências e padrões nos dados.

## 🛠️ Ferramentas utilizadas

* **Microsoft Power BI Desktop** — criação do dashboard e das visualizações interativas.
* **Power Query** — preparação e transformação dos dados.
* **DAX** — criação de medidas e indicadores, quando aplicável.

## ✨ Recursos do dashboard

* Gráficos interativos para exploração dos dados.
* Comparação de vendas por ano e categoria.
* Visualização dos indicadores de desempenho.
* Análise dinâmica das informações apresentadas.
