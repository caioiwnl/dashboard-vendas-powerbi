# Dashboard de Vendas — Power BI

## Sobre o projeto

Dashboard interativo desenvolvido no Microsoft Power BI para visualizar e analisar dados de vendas.

## Objetivos

* Analisar vendas por gênero.
* Comparar resultados por ano.
* Facilitar a visualização dos indicadores de desempenho.

## Ferramentas utilizadas

* Microsoft Power BI Desktop
* Power Query
* DAX (se utilizado no projeto)
